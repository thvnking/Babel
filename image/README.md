# Danh mục ảnh game Babel

Tên file dùng tiền tố để nhận diện ngay vai trò của ảnh; thư mục chia theo nhóm nội dung.

## Menu

| Đường dẫn | Vai trò | Nguồn nhận diện |
|---|---|---|
| `ui/menu/menu_background.png` | Nền menu chính | Thánh đường Gothic trên vực thẳm; đang được menu sử dụng. |
| `ui/menu/menu_panel_frame.png` | Khung panel Gothic vuông | Khung giao diện Gothic đồng cổ trên nền trong suốt. |
| `ui/menu/menu_button_frame.png` | Khung nút menu nằm ngang | Khung giao diện đá Gothic mạ đồng. |

## Gameplay hiện có

- `rooms/room_monster.jpg`, `room_trap.jpg`, `room_pray.jpg`, `room_teleport.jpg`, `room_event.jpg`, `room_bonfire.jpg`: nền sáu loại phòng.
- `characters/player_avatar.jpg`: chân dung prototype người chơi.
- `enemies/monster_d1.png`: hình quái prototype.

Ảnh mới hãy đặt trong thư mục gốc `place put image`; xem quy tắc đặt tên và danh sách asset cần tạo tại [README](../place%20put%20image/README.md). Sau khi tích hợp, chuyển ảnh sang nhóm thích hợp trong `image/` và cập nhật tham chiếu Godot nếu cần.
